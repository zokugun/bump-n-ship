Changelog
=========

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog][keepachangelog], and this project adheres to [Semantic Versioning][semver].

[v0.3.0] | 2026-11-22
---------------------

### Added

- add `publish.whenComplete.open` setting to open an url when publish has been completed

[v0.2.0] | 2026-11-22
---------------------

### Added

- use the `interactive` setting to `confirm`, `pause` or not at each step

[v0.1.2] | 2026-11-18
---------------------

### Fixed

- fix git command due to extra space in an argument

[v0.1.1] | 2026-11-15
---------------------

### Fixed

- pass `npm_new_version` and `npm_old_version` env variables to npm scripts

### Chore

- move the `loadGitTokens` function to the `@zokugun/git-toolkit` package

[v0.1.0] | 2026-11-13
---------------------

### Added

- initial release
